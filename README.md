# Toan To Portfolio — Frontend Clone

A frontend-only clone of [toan.framer.website](https://toan.framer.website/), the UX designer portfolio of Toan To.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage — hero marquee, case study grid, about, contact |
| `/anz` | ANZ Bank case study (full content) |
| `/pi` | Property Analytics case study (full content) |

## Tech Stack

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (animations)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Notes

- Images are loaded from the original Framer CDN (`framerusercontent.com`).
- Two case study cards (Espresso App, UX Psychology Tool) are marked "Coming Soon" and are not linked, matching the original site.
- This is a frontend clone for educational/portfolio purposes.
